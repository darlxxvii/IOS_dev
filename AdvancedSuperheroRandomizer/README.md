# Superhero Randomizer (iOS)
An iOS application that fetches a random superhero from the SuperHero API and displays detailed information, including stats, biography, and an image.

## Features:
* Fetches a random superhero with one tap
* Displays:
  * Name and full name
  * Powerstats (intelligence, strength, speed, durability, power, combat)
  * Biography and appearance
  * Large hero image
* Saves and loads the last viewed hero using UserDefaults
* Scrollable interface with dynamic content

## Tech Stack:
* Swift / UIKit
* Alamofire (networking)
* Kingfisher (image loading and caching)
* SuperHero API: [https://akabab.github.io/superhero-api/](https://akabab.github.io/superhero-api/)
